# LordMi Works 視覺與頁面規範

所有新子頁必須使用 Layout → Header → Main → Footer。Main 統一產生麵包屑、H1、描述與內容區，不可在頁面重寫主標或容器。

- 一般子頁、文章列表、分類、搜尋、關於我統一 reading-container（45rem 內容寬），左右 gutter 相同。
- 麵包屑上距 24px，Main 上距 24px，H1 margin 為 0。描述上距 12px，內容區上距 32px。不得為個別頁面另加頂部留白。
- H1 使用 display 襯線及 --type-page-title（32–48px）。H2 使用黑體及 --type-section-title（24–32px），H3 使用黑體及 --type-subsection-title（20px）。禁止局部重設字級。
- 主文使用 body 字型；長文 17–18px、行高 1.85。日期與標示 14px。正文與結構標題不可因頁面任意變色。
- 背景淡米白，頁首暖米色、頁尾深米色；品牌與標題深藍，正文深褐，互動陶土色。只能使用 base.css tokens。
- 首頁 Hero 為唯一寬版主視覺例外，子頁不得複製 Hero 版型。文章詳情保留作者日期與閱讀導覽，但沿用閱讀容器及標題 token。
- 無封面的文章使用文字卡片，窄版列表最多兩欄，手機一欄。
- 新增頁面須驗證 390px 與桌面，快速切換關於我、專業服務、方法與案例、文章與觀點，確認 H1 左緣、上緣、字級一致。長標題自然換行，不固定高度截字。
- 不得更改 CMS schema、文章 slug 或路由來解決視覺問題。
